🧠 Los 5 Principios Fundamentales del Examen PDE

1. Administrado y Serverless Primero: Siempre prefiere Dataflow, BigQuery y Datastream sobre clusters de cómputo auto-gestionados, a menos que código legacy requiera Dataproc.

2. Desacoplar Almacenamiento y Cómputo: Nunca persistas datos críticos en discos locales de los workers; usa Cloud Storage, BigQuery o Bigtable como capas de almacenamiento desacopladas.

3. Desnormalizar en BigQuery: Reemplaza los JOINs multi-tabla con campos RECORD (STRUCT) y REPEATED (ARRAY) para eliminar cuellos de botella de shuffle distribuido.

4. Seguridad por Diseño: Aplica IAM de mínimo privilegio, claves administradas por el cliente (CMEK) vía Cloud KMS, y tokenización de datos sensibles (DLP) para PII.

5. Escalabilidad Dirigida por Eventos: Combina Cloud Pub/Sub con Cloud Dataflow usando watermarks de tiempo de evento y latencia permitida para flujos desordenados.
