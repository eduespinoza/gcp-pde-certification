🧠 The 5 Core Principles of the PDE Exam

1. Managed & Serverless First: Always prefer Dataflow, BigQuery, and Datastream over self-hosted compute clusters unless legacy code demands Dataproc.

2. Decouple Storage and Compute: Never persist mission-critical data on worker local disks; leverage Cloud Storage, BigQuery, or Bigtable as external decoupled tiers.

3. Denormalize in BigQuery: Replace multi-table SQL joins with RECORD (STRUCT) and REPEATED (ARRAY) fields to eliminate distributed shuffle bottlenecks.

4. Security by Design: Enforce Least Privilege IAM, Customer-Managed Keys (CMEK) via Cloud KMS, and Sensitive Data Protection (DLP) tokenization for PII.

5. Event-Driven Scalability: Pair Cloud Pub/Sub with Cloud Dataflow using event-time watermarking and allowed lateness for out-of-order streams.
